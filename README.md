# Website Công ty In Mộc Ấn – inmocan.vn

Web tĩnh chạy trên GitHub Pages (nhánh `main`, thư mục gốc), gắn tên miền `inmocan.vn` qua file `CNAME`.

- `index.html`: toàn bộ trang (trang chủ, giới thiệu, sản phẩm, năng lực xưởng, kiến thức, liên hệ)
- `bo-so-lich.html`: công cụ Bộ số lịch
- `p/`: ảnh sản phẩm (ảnh minh hoạ)
- `v/`: video xưởng và ảnh bìa video
